# 🌸 Irina Synthetica interactive Portfolio & Classroom CRM

Интерактивное генеративное портфолио, оранжерея ИИ-образов и практические мини-курсы Ирины Synthetica по ИИ-брендингу, нейромаркетингу и наставничеству со встроенной базой данных студентов и домашних заданий.

---

## 🚀 Архитектура приложения

Приложение построено на современном и быстром стеке **Full-Stack (React + TS + Vite + Express + Node.js)**:
- **Frontend**: React-компоненты с изящным оформлением на Tailwind CSS, анимациями `motion` и панелью управления CRM.
- **Backend**: Express-сервер, который управляет загрузкой файлов клиентов, транскрипцией, интеграцией с API Gemini и центральной базой данных.
- **База данных**: Файловая JSON-база данных на стороне сервера (`public/uploads/classroom_db.json`), хранящая полный реестр студентов, их прогресс по лекциям, отметки о прохождении курсов и все выполненные практические домашние задания и результаты тестов.

## 📦 Как перенести сайт на свой GitHub

Вы можете перенести свой сайт на GitHub двумя простыми способами:

### Способ 1: Автоматический экспорт через Google AI Studio (Самый простой)
1. В правом верхнем углу интерфейса **Google AI Studio** найдите и откройте меню настроек (**Settings** или иконку шестерёнки).
2. Выберите опцию **Export to GitHub** (Экспортировать на GitHub) или **Download ZIP** (Скачать архив).
3. Если вы выбрали **Export to GitHub**, авторизуйте свой аккаунт GitHub, и платформа автоматически создаст для вас новый репозиторий со всем кодом.
4. Если вы скачали ZIP-архив, распакуйте его на компьютере и следуйте инструкции «Способ 2» ниже, чтобы загрузить его на GitHub вручную.

### Способ 2: Ручная загрузка через Git
Если вы скачали проект в виде ZIP-архива, выполните следующие команды в терминале папки проекта:

1. Инициализируйте репозиторий:
   ```bash
   git init
   ```
2. Добавьте все файлы проекта:
   ```bash
   git add .
   ```
3. Сделайте первый коммит:
   ```bash
   git commit -m "Initial commit: Irina Synthetica Full-Stack Portfolio CRM"
   ```
4. Создайте новый публичный или приватный репозиторий на вашем сайте [GitHub](https://github.com), скопируйте его URL и привяжите к вашей локальной папке:
   ```bash
   git branch -M main
   git remote add origin URL_ВАШЕГО_РЕПОЗИТОРИЯ
   ```
5. Отправьте код на GitHub:
   ```bash
   git push -u origin main
   ```

## 🛠️ Запуск проекта на локальном компьютере

Для того, чтобы запустить это Full-Stack приложение локально на вашем компьютере, вам понадобится установленный [Node.js](https://nodejs.org/) (версии 18 или новее).

### 1. Установка всех зависимостей
Перейдите в папку с распакованным проектом в вашем терминале и выполните установку библиотек:
```bash
npm install
```

### 2. Создание файла конфигурации окружения `.env`
Создайте в корневой директории проекта конфигурационный файл с именем `.env` и добавьте туда ваш API-ключ Gemini:
```env
GEMINI_API_KEY=ваш_секретный_api_ключ_от_google_ai_studio
```

> **Важно**: Никогда не публикуйте и не выкладывайте свой точный файл `.env` на GitHub. Он по умолчанию добавлен в список исключений `.gitignore`.

### 3. Запуск сервера в режиме разработки (Dev)
Запустите интегрированный сервер разработки, который соединяет Express-бэкенд на порту 3000 и горячую перезагрузку фронтенда (HMR):
```bash
npm run dev
```
После запуска откройте браузер по адресу: **`http://localhost:3000`**

### 4. Сборка для публикации (Production Build)
Чтобы скомпилировать фронтенд и бэкенд в оптимизированный для работы в "живом" интернете вид:
```bash
npm run build
```
Запуск скомпилированной версии:
```bash
npm run start
```

## 🗄️ Структура данных (База CRM обучения)

Вся учебная активность теперь сохраняется в файл базы данных `public/uploads/classroom_db.json`. База структурирована следующим образом:
- **`students`**: Массив объектов учащихся. Включает ID студента, имя, email, хэш/пароль, статус участия в менторстве и списки выданных персонально курсов и модулей учебной программы.
- **`completedLessons`**: Карта пройденных лекций. Имеет формат: `"IDкурса_IDмодуля_индексЛекции_IDстудента": true`. Это исключает потерю прогресса уроков при очистке кэша браузера.
- **`submissions`**: Записи всех отправленных домашних заданий, ссылок на практические работы, комментариев и итоговых баллов за проверочные тесты модулей.

Ирина, как администратор, может мгновенно управлять этим реестром в реальном времени из встроенного интерфейса Classroom!
